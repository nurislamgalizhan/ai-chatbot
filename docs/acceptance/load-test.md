- Полная цепочка: уведомление провайдера → входящая очередь → чат и сообщение → (голосовое: задача медиа, проверка длительности, транскрибация) → конвейер ИИ → ответ в БД → outbox (DRY_RUN: помечено, не отправлено).
- «Макс. параллельных вызовов» — сколько вызовов модели шло одновременно; предел SPEC §16 — 8.
- «Порядок нарушен» — второй раунд шлёт в каждый чат ещё одно сообщение; ответ на него должен появиться после ответа на первое.
