## Общая структура

Левый сайдбар (тёмный пункт = активный раздел), фиксированный на всех экранах:
- Лого + название сервиса, кнопка сворачивания сайдбара
- Блок баланса: сумма, "хватит на N дней", отдельная строка расхода за
  что-то вроде минут/токенов (иконка молнии)
- Пункты меню: Чаты, Агенты, Савви.Маркет, Рассылки, История, Аналитика,
  Логи запросов
- Низ сайдбара: "Партнёрская программа", "Руководство по платформе",
  переключатель языка (флаг + название), "Поддержка" (с зелёным индикатором
  онлайн)

Правый верхний угол на всех экранах: аватар + имя/email текущего пользователя.

Общий стиль: светлый фон (светло-серый/голубоватый), карточки на белом фоне
с мягкими тенями/скруглениями, синий/тёмно-синий акцентный цвет, красный —
для расходов/убывающих величин, зелёный — для позитивных статусов
(включено/онлайн).

## 1. Экран "Аналитика" → вкладка "Общее"

- Вкладки сверху: Общее / Звонки / Оценки
- Панель "Сформировать статистику": выбор агента (dropdown "Все агенты"),
  выбор периода (dropdown "Последние 30 дней"), кнопка
  "Сформировать статистику", кнопка "История" справа
- Карточка "Статистика ответов": три крупные метрики с цветными точками
  (всего сообщений / обработано ботом / кол-во диалогов) + линейный график
  по дням (3 линии разных цветов) с подсказкой "нажмите на точку, чтобы
  посмотреть данные за день"
- Карточка "Средняя стоимость": крупное значение (напр. "20₽") + столбчатая
  диаграмма по дням
- Карточка "Эффективность Савви": пончиковая диаграмма (donut chart) —
  % обработано ботом vs не обработано, легенда слева с цветными точками
- Карточка "Использование тегов": горизонтальный прогресс-бар/бар-чарт с
  % использования тегов, легенда сверху

## 2. Экран "История"

- Кнопка "Новый агент" в правом верхнем углу
- Вкладки: История / Отчёты
- Панель фильтров: Период (dropdown), Агент (dropdown), Источник (text),
  ID диалога (text), Текст вопроса/ответа (text), чекбокс "Показывать
  только ответы агента"
- Строка тегов: "#Теги", поле "Добавить тег...", иконка настроек справа
- Таблица истории диалогов, колонки: Дата, Агент, Ист. (источник/оператор),
  Канал (иконка WhatsApp), Вопрос, Ответ, Действия (иконки: свернуть/раскрыть,
  список, профиль)
- Под вопросом/ответом — мелким текстом стоимость сообщения в рублях
  (напр. "2.66 ₽", "0.08 ₽")

## 3. Экран "Баланс" → вкладка "Транзакции"

- Вкладки: Баланс / Транзакции / Платёжные данные / Документы
- Кнопка "Пополнить баланс" в правом верхнем углу
- Слева: под-вкладки "Списания" / "Пополнения", таблица (Дата, Операция
  [сумма красным с минусом], Остаток, Тип)
- Справа: выбор периода (диапазон дат), "График использования" —
  столбчатая диаграмма по дням с суммой в подписи легенды (напр.
  "RUB (Всего 5,293.93 ₽)"), ниже "Статьи расходов" с двумя dropdown-фильтрами
  и второй столбчатой диаграммой

## 4. Экран агента → вкладка "Инструкция"

- Хлебная крошка/заголовок: название агента в кавычках (напр.
  ""УЦ Меркурий Медет"")
- Вкладки: Инструкция / Доп. настройки / База Знаний / Действия / Каналы /
  Интеграции / Анализатор
- Баннер-подсказка (розовая рамка): "Составьте базу знаний из переписок" +
  кнопка "Перейти" + крестик закрытия
- Строка настроек: "Режим работы" (переключатель Текст/Голос, каждый со
  своей иконкой), "Имя AI-агента" (текстовое поле с info-иконкой),
  "Время ожидания" (dropdown), справа — виджет прогресса настройки агента
  (круговой % + текст "Агент работает" / "Дальше: Анализ переписок",
  булавка для закрепления)
- Редактор "Инструкции": тулбар (undo/redo, "Целевые действия",
  "Карточка клиента", кнопка полноэкранного режима), справа — кнопки
  "Сгенерировать инструкцию" и "Улучшить ответы агента"
- Сам текст инструкции — с номерами строк, структурирован Markdown-like
  заголовками в верхнем регистре с "#" (#РОЛЬ, #ЦЕЛИ И ЗАДАЧИ,
  #ПРИВЕТСТВИЕ, #ЯЗЫК ОТВЕТОВ, #СТИЛЬ ОТВЕТА, #ЛОГИКА ПОСТРОЕНИЯ ДИАЛОГА
  с шагами "Шаг 1/2/3...")
- Справа от редактора — вертикальная панель кнопок для вставки блоков:
  комментарий (//), заголовок (#), под-заголовок, код (<>), переменная ({})

## 5-7. Экран агента → вкладка "Доп. настройки"

Левое под-меню (вертикальный список): Параметры LLM, Параметры ответов,
Фоллоу-апы, Рабочее время, Защита от спама, Польз. переменные, Стандартные
функции, Безопасность, Системные действия.

**Параметры LLM**: выбор языковой модели (dropdown, напр. "GPT-5.2"),
переключатель "Указать языковую модель для тестового чата"; блок
"Разговорчивость" — три кнопки-таба (Низкая/Средняя/Высокая) с пояснением
под ними о влиянии на длину ответов; блок "Параметры ответа" — числовые
степперы "Макс. кол-во токенов в ответе" и "Лимит параллельного вызова
функций"; блок "Структурированный ответ" — тумблер "Использовать
структурированный ответ".

**Параметры ответов**: "Время ожидания в тестовом чате" — ряд кнопок
(Не задано / 0 сек / 10 сек / 20 сек / 30 сек / 60 сек / Любое); "История
сообщений (контекст)" — dropdown "Передавать всю историю"; тумблер
"Сохранять историю вызова функций"; блок "Условия прерывания" — тумблеры
("Не отвечать при прерывании диалога сотрудником", "Игнорировать первые
сообщения от сотрудника", "Указать фразы по которым прерывание срабатывать
не будет"); блок "Условия возобновления диалога" — тумблер "Возвращение
управления агенту по таймеру" со степпером "Время возвращения управления
агенту в минутах" (напр. 60), тумблер "Возобновление диалога по фразам
сотрудника".

**Рабочее время**: dropdown выбора часового пояса (напр.
"(GMT+05:00) Yekaterinburg"), тумблер "Указать рабочее время" (детальное
расписание скрыто, пока выключено).

**Защита от спама**: тумблеры "Максимальное количество сообщений в
диалоге", "Максимальная стоимость диалога"; степпер "Максимальное
количество одинаковых сообщений от клиента подряд" (напр. 5); тумблер
"Период работы защиты от спама".

## 8. Экран агента → вкладка "База Знаний"

- Под-вкладки: "Вопрос — ответ" (с счётчиком, напр. 10), "Самообучение"
  (с бейджем "NEW", счётчик 0), "Документы" (0), "Таблицы" (0)
- Пояснение под вкладками: "Пары «вопрос клиента — ответ». Самый быстрый и
  точный раздел: работает без векторизации. Оптимально до 50 записей —
  дальше каждый ответ агента заметно дороже."
- Кнопки: "+ Добавить", "Автоматическая генерация" (выделена
  розовым/акцентным цветом), "Настройки", поле поиска, иконка фильтра,
  dropdown экспорта "Excel"
- Список записей: заголовок на русском + подпись на английском под ним
  (напр. "Абонементы в тренажерный зал" / "Gym Memberships"), справа для
  каждой записи: кнопка "STOP", колокольчик (уведомления), тумблер
  включения/выключения записи (зелёный = вкл), меню "⋮"

## 9. Экран "Чаты"

- Переключатель "Продвинутый режим" в заголовке (с info-иконкой)
- Левая колонка: поиск по диалогам, кнопка "+ Тестовый чат", список
  диалогов — аватар-инициал (цветной круг), имя контакта, время последнего
  сообщения, превью последнего сообщения, тег с именем агента (иконка
  WhatsApp зелёная точка на аватаре = канал), статусы вроде "Диалог прерван"
  или "Оператор"
- Правая колонка — окно диалога: имя контакта + номер телефона в заголовке,
  тумблер "AI-агент активен" (зелёный = включён), ряд иконок действий
  (лайк/дизлайк? запрет, конверт, редактировать, молния, "отправить/выгрузить")
- Сообщения — чат-пузыри: слева от клиента (с инициалом-аватаром), справа —
  от агента (с иконкой бота, названием агента, info-иконкой), таймстемп
  у каждого сообщения
- Поле ввода снизу с иконкой скрепки (вложение), микрофоном, кнопкой отправки

## Что взять на вооружение для нашего бота

- Чёткое разделение "Агент" (конфигурация: инструкция / доп.настройки /
  база знаний / каналы / интеграции) от "Чатов" (живые диалоги) и
  "Истории"/"Аналитики" (отчётность) — хорошая верхнеуровневая архитектура
  разделов.
- Инструкция агента как структурированный текст с секциями
  (#РОЛЬ, #ЦЕЛИ, #СТИЛЬ, #ЛОГИКА ДИАЛОГА по шагам) — удобный формат для
  промпт-инжиниринга, который сам пользователь может редактировать.
  Плюс кнопки-помощники "Сгенерировать инструкцию" / "Улучшить ответы агента".
  У нас интеграция будет через Green API, поэтому вкладка "Каналы" будет
  проще (один канал).
- Прозрачная стоимость: cost-per-message/диалог показывается прямо в
  истории и в балансе — полезный паттерн, если у нас будет
  pay-per-use/биллинг.
- Q&A база знаний с явным лимитом "до 50 записей без потери скорости" —
  хороший UX-приём, объясняющий пользователю trade-off векторного поиска.
- Настройки анти-спама (макс. одинаковых сообщений подряд, лимит стоимости
  диалога) и условия прерывания/возобновления диалога человеком-оператором —
  важные функции, которые стоит заложить в архитектуру бота с самого начала.
